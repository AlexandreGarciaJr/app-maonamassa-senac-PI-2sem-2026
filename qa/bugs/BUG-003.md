# BUG-003 — [Navegação] Falha de rede ao abrir uma tela mostra "Página não encontrada"

- **Severidade:** médio · **Prioridade:** P2
- **Ambiente:** localhost:5173, Edge, rede da tela Agenda bloqueada (`page.route`)

**Passos**
1. Abrir a home.
2. Simular falha de rede no carregamento do código da Agenda.
3. Tocar em "Agenda" na barra inferior.

**Obtido:** "Página não encontrada. O endereço pode estar errado..." e só um botão para o início.
**Esperado:** mensagem de falha de conexão com opção de tentar de novo; "não encontrada" só para endereço inexistente.
**Frequência:** sempre · **Evidência:** `qa/sessoes/evidencias/c5-falha-rede.png`
**Status:** corrigido (tela de erro própria) + teste E2E de regressão.
